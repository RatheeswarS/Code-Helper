# Exp7 Gradle

Gradle Java project: build and JAR

## Questions

- **Q21** `Q21_SimpleInterest_Gradle/` - Develop a Java application to calculate simple interest using the principal amount, rate of interest, and time period provided as input. Create a Gradle Java project, configure the build.gradle file, and build the application to generate the required build artifacts.

- **Q22** `Q22_ArrayAverage_Gradle/` - Develop a Java application to read five numbers into an array and calculate their average. Configure a Gradle Java project to compile the source code and package the application into a JAR file.

- **Q23** `Q23_VowelConsonant_Gradle/` - Develop a Java application to read an English alphabet character and determine whether it is a vowel or a consonant. Create a Gradle Java project, configure the build script, and compile and package the application into a JAR file.

- **Q24** `Q24_Rectangle_Gradle/` - Develop a Java application to read the length and breadth of a rectangle and calculate its area and perimeter. Configure a Gradle Java project to build the application and generate the JAR file.


Each question folder = ready project + `*_ALL_IN_ONE.md` (question, aim, procedure, all code, xml/yml, commands, output).


## Viva-voce

- **What is Gradle?** Build tool using Groovy/Kotlin DSL; faster incremental builds than Maven.
- **build.gradle vs settings.gradle?** build.gradle = build config; settings.gradle = project name / modules.
- **java vs application plugin?** java = compile/test/jar; application = run task + distributions.
- **Gradle wrapper?** gradlew script that downloads the right Gradle version.
- **Where is the JAR?** build/libs/
